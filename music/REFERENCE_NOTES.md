# BGM reference notes ("recipes", not audio)

Nani shares film BGMs as **inspiration only**. The audio files are never stored in this repo
(they are copyrighted). Only the measured *feel* is recorded here, and every track we publish
is composed from scratch with `mass_kit.py` (no copied melody, no samples).

## How to use these notes
Pick a reference whose feel fits the scene, then build an original cue with the same
tempo range, key colour, energy shape and instrument palette — never the same tune.

## 1. Varanasi teaser (SS Rajamouli) — analysed 2026-11-28
| Property | Measured |
|---|---|
| Tempo | ~133 BPM |
| Key | A minor (dark, epic) |
| Energy shape | very slow, long build: near-silent for ~15 s, gradual rise, biggest peak at the very end |
| Spectrum | mid-heavy (~47% mid, 23% presence) → orchestra, choir, brass carry it; moderate sub |
| Onset density | ~1.5 hits/s (spacious, big hits rather than busy patterns) |

**Recipe:** low minor drone + male choir swells + staccato strings ostinato that tightens,
big braams on story beats, dhol/taiko that gets denser toward the peak, riser into a final hit.
**Used in:** Bhumi origin (earthquake build), Bindu origin (villain tease ending).

## 2. "Make Way for the King" — Raaka theme (Sai Abhyankkar) — analysed 2026-11-28
| Property | Measured |
|---|---|
| Tempo | ~72 BPM half-time feel (144 double-time) |
| Key | F major (bright, royal, heroic) |
| Energy shape | hits hard from the start and stays high, small dip near the end |
| Spectrum | strong sub (~10%), bright presence (~26%) → heavy 808/kick + brass/chants on top |
| Onset density | ~2 hits/s (dense percussion) |

**Recipe:** major-key hero drop, half-time groove (kick on 1, big clap/taiko on 3, dhol slaps
in 8ths), sliding 808 sub, crowd "HEY!" chants on accents, brass hero melody, choir chords.
**Used in:** Bhumi origin (the drop at 19.8 s), Bindu origin (montage + name slam).

## House sound (what makes our channel recognisable)
- Old meets new: tanpura / bansuri / dhol + modern 808, claps, lo-fi or phonk drums.
- Story-first structure: quiet emotional intro → build → drop on the hero moment → name slam on a beat.
- Grid: 144 BPM (half-time 72) for action; 80 BPM for calm lo-fi.
